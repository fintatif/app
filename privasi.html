FINTATIF Smart Wealth

Kebijakan Privasi

Berlaku sejak 31 Oktober 2026

FINTATIF Smart Wealth adalah aplikasi pencatatan keuangan pribadi yang dibuka lewat browser di fintatif.github.io/app. Halaman ini menjelaskan data apa yang kami simpan, data apa yang tidak bisa kami lihat, dan pilihan yang kamu punya.

Data akun yang kami simpan

Untuk mendaftar dan masuk, kami menyimpan nama, alamat email, status akun, tanggal daftar, dan nominal transfer pembayaran di database FINTATIF. Data ini hanya dipakai untuk memverifikasi pembayaran, mengaktifkan akun, dan mengirim email terkait akunmu.

Catatan keuanganmu

Transaksi, saldo, kategori, utang piutang, tagihan, target tabungan, dan data proteksi tersimpan di browser perangkat yang kamu pakai. Catatan ini tidak dikirim ke server FINTATIF.

Kamu bisa mengunduh salinannya kapan saja sebagai file cadangan .fintatif, atau menyimpannya ke Google Drive milikmu sendiri seperti dijelaskan di bawah.

Fitur Simpan ke Google Drive

Fitur ini opsional. Kalau kamu menekan Hubungkan Google, aplikasi meminta satu izin Google, yaitu drive.file. Dengan izin ini aplikasi hanya bisa membuat dan mengubah file yang dibuatnya sendiri, yaitu Google Sheet "FINTATIF Smart Wealth - Data Saya" di Drive milikmu. Aplikasi tidak bisa membuka file lain di Drive-mu.

  • Data dikirim langsung dari browsermu ke Google. Data tidak melewati server FINTATIF, jadi FINTATIF tidak bisa membuka atau membaca isinya.
  • Tanda akses (token) Google hanya disimpan sementara di memori browsermu, tidak disimpan permanen, dan tidak dikirim ke FINTATIF.
  • Kami tidak menjual, membagikan, atau memakai data dari Google untuk iklan, dan tidak memakainya untuk melatih model kecerdasan buatan.
  • File di Google Drive tetap milikmu. Kamu bisa menghapusnya kapan saja.

Penggunaan dan pemindahan informasi yang diterima FINTATIF Smart Wealth dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses Google

Tekan Putuskan di halaman Backup Data, atau buka myaccount.google.com/permissions lalu hapus akses FINTATIF Smart Wealth.

Menghapus akun

Kirim permintaan ke email di bawah dan kami akan menghapus data akunmu dari database FINTATIF. Catatan di perangkatmu dan file di Google Drive-mu bisa kamu hapus sendiri.
