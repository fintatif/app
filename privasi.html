FINTATIF Smart Wealth

Kebijakan Privasi

Berlaku sejak 31 Oktober 2026 · diperbarui 2 November 2026

FINTATIF Smart Wealth adalah aplikasi pencatatan keuangan pribadi yang dibuka lewat browser di fintatif.github.io/app. Halaman ini menjelaskan data apa yang kami simpan, data apa yang tidak bisa kami lihat, dan pilihan yang kamu punya.

Data akun yang kami simpan

Untuk mendaftar dan masuk, kami menyimpan nama, alamat email, status akun, tanggal daftar, dan nominal transfer pembayaran di database FINTATIF. Data ini dipakai untuk memverifikasi pembayaran, mengaktifkan akun, mengirim email terkait akunmu, dan mengirim kabar pembaruan aplikasi.

Password-mu tersimpan terenkripsi, jadi tidak bisa dibaca siapa pun, termasuk FINTATIF. Kode 6 angka untuk membuat atau mengganti password dikirim ke emailmu dan hanya berlaku 10 menit.

Catatan keuanganmu

Transaksi, saldo, kategori, utang piutang, tagihan, target tabungan, dan data proteksi tersimpan di browser perangkat yang kamu pakai. Catatan ini tidak dikirim ke server FINTATIF. Kunci PIN dan foto profil juga hanya tersimpan di perangkat itu.

Kamu bisa mengunduh salinannya kapan saja sebagai file cadangan .fintatif atau file Excel, atau menyimpannya ke Google Drive milikmu sendiri seperti dijelaskan di bawah.

Fitur Simpan ke Google Drive

Fitur ini opsional. Kalau kamu menekan Hubungkan Google, aplikasi meminta izin Google Drive drive.file dan alamat email akun Google-mu. Kamu bebas memilih akun Google mana saja, tidak harus sama dengan email akun FINTATIF-mu. Email itu hanya disimpan di perangkatmu supaya perangkat itu terus memakai akun Google yang sama. Dengan izin drive.file aplikasi hanya bisa membuat dan mengubah file yang dibuatnya sendiri, yaitu Google Sheet "FINTATIF Smart Wealth - Data Saya" di Drive milikmu. Aplikasi tidak bisa membuka file lain di Drive-mu.

  • Data dikirim langsung dari browsermu ke Google, tidak melewati server FINTATIF, jadi FINTATIF tidak bisa membuka atau melihat data kamu.
  • Izin Google (token akses yang berlaku sekitar 1 jam) hanya disimpan di browser perangkatmu dan tidak pernah dikirim ke server FINTATIF. Izin itu diperpanjang otomatis di latar belakang, langsung antara browsermu dan Google.
  • Tombol Putuskan sambungan mencabut izin itu dan menghapusnya dari perangkatmu. Kamu juga bisa mencabutnya kapan saja di myaccount.google.com/permissions.
  • Kami tidak menjual, membagikan, atau memakai data dari Google untuk iklan, dan tidak memakainya untuk melatih model kecerdasan buatan.
  • File di Google Drive tetap milikmu. Kamu bisa menghapusnya kapan saja.

Penggunaan dan pemindahan informasi yang diterima FINTATIF Smart Wealth dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses Google

Tekan Putuskan sambungan di halaman Backup Data, atau buka myaccount.google.com/permissions lalu hapus akses FINTATIF Smart Wealth.

Menghapus akun

Kirim permintaan ke email di bawah dan kami akan menghapus data akunmu dari database FINTATIF. Catatan di perangkatmu dan file di Google Drive-mu bisa kamu hapus sendiri.
